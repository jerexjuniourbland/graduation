CLASS BOOK GENERATOR – UPGRADED

Features:
- Up to 40 students, entered one by one.
- Student photo crop tool with zoom, horizontal and vertical adjustment.
- Student profile: circular photo, Jina, Somo analopenda, Ndoto yake.
- Staff Members: photo, name and job/title; add/edit/delete one by one.
- Official Guest page: photo, name, title and message.
- Head of School page: photo, name, title and message.
- Front cover and closing page.
- Preview uses A4 pages; students are 12 per page in 4 x 3 layout.
- Print / Save as PDF.
- Real .DOCX generation using bundled JSZip.
- Student/staff records are stored in IndexedDB; settings/media in browser local storage.

IMPORTANT:
1. Open index.html using Chrome or Microsoft Edge.
2. If an older version is already open, close it and reopen this version.
3. DOCX is generated as a real .docx file, not a renamed .doc file.
